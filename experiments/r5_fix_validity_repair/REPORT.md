# R5-FIX — 重建与评估有效性修复报告

日期：2026-09-09。
范围：仅修复 R4–R5.6 中已被独立评审确认的实现与评估缺陷，重新生成被污染的对比，并检验"接触条件化重建"这一核心结论在修正后是否仍然成立。
本阶段**不**是新研究方向、不调检测器、不做生产集成。历史输出一律未改动，仅读取。

**结果先行（TL;DR）**

1. 历史缺陷全部复核属实并精确复现（旧 C1 WAV 与缺陷实现逐样本一致，float32 误差为 0；旧 C2 误差 2.8e-17）。
2. 修正版 C1 通过全部确定性测试：入口 0→1 平滑上升、内部恒 1、出口 1→0 平滑下降、重叠取 max、无任何不连续。
3. 修正版 C1 **没有**实质改变真实的事件保留（golden 起音保留 64/84，新旧相同），但**几乎消除了边界咔哒伪迹**（golden 干声中"多余的输出起音"从 24 个降到 3 个）。历史上报告的"保留量"有一部分是缺陷包络的入场跳变点击制造的。
4. 已知休息段 [6,8] s 的暴露**与包络修复无关、完全没有改善**（E0：1.425 s 增益>0，能量仅比原始低 1.8 dB）——这是**检测器**在休息段内给出预测造成的；oracle 时序下休息段精确为 0。
5. 修正后的打击乐 HPSS 对照不再"毁掉敲击"（事件峰值比中位数 0.57→0.86），但仍劣于修正版 C1：旧的 HPSS 否结论方向正确、论据作废。
6. 等覆盖时移对照证明**正确的时序位置本身承载收益**：时移后保留下降（golden 64→50）、幅度相关性崩落（0.96→0.68）、休息段暴露恶化（1.42→1.73 s）。
7. 决策门选择 **A**：基础已修复到可以进入**新录音独立验证阶段**；不进入 R6，不宣称生产就绪。

## 1. 确认的历史缺陷

全部缺陷先用冻结的历史代码**原样复现**（`logs/historical_reproduction_checks.json`，全部通过）之后才开始修复：

### 1.1 C1 包络（攻击/释放斜坡互换）

`envelope_from_spans`（R4 `20_build.py` → R4.5 → R5/R5.5/R5.6 公共代码原样继承）在窗口开头使用 `ramp_dn`（1→0）、结尾使用 `ramp_up`（0→1），再 abruptly 落回 0。实测旧 golden C1 WAV：
- 0.055458 s：0 → 1 跳变（入场即满增益）；
- 0.065458 s：增益降至 0，0.065479 s 又跳回 1（攻击段内 0→1 跳变）；
- 0.470167 s：1 → 0 跳变（释放开始前）；
- 0.530167→0.530187 s：升回 1 后最终跌到 0。

本阶段用旧实现从存储的预测重建 C1，与历史 WAV **逐样本一致**（float32 最大误差 0.0），R4.5 D0 同样复现（评审已验证 D1 是 D0 的逐点超集）。

### 1.2 C2 HPSS（掩码方向颠倒）

STFT 维度为 频率×时间。旧实现把**时间轴中值**（= 谐波/持续结构估计）放在所谓"打击乐掩码"的分子（`M = Zp/(Zh+Zp)`，其中 `Zp = median(size=(1,31))` 沿时间）。该掩码实际增强持续谐波、压制瞬态——与标准 Fitzgerald 中值滤波 HPSS 相反。本阶段原样复现旧 C2 WAV（误差 2.8e-17）。

### 1.3 评估器（多处失效指标）

- 事件匹配用最近邻贪心，非一一对应（±80 ms 时贪心 78 对 vs 最优 80 对，本阶段已复现）；
- "动态相关性"实为 `corr(peak_ratio, raw_peak)`，恒等处理下无定义/无意义；
- `false_onsets` 把输出起音数组与 oracle 事件索引 zip，实体集错配；
- "false-window 时长"从波形 `|x|>1e-6` 反推门区间，并按区间**中点**分类整段——波形阈值、立体声抵消都会污染它；
- "Taiko leakage"（太鼓泄漏）标注没有任何独立太鼓事件证据，且 JSON 里 E0/E2 实际都是 0；
- 归一化最终混音 RMS 被当作"感知接近度"（两版混音共享同一 0.5×参考，差值相消、分母被抬高）；
- `VISUAL_HIGH`（标注置信度）与 `AUDIO_STRONG`（音频瞬态对比度）混用为"strong"。

## 2. 修正实现

### 2.1 修正包络（精确定义；窗口策略本身未动：pre 15 ms / post 150 ms）

- 窗口外：增益 = 0；
- 入口：10 ms 升余弦 0→1，`env[s]==0` 精确、`env[s+A]==1` 精确，连续进入内部；
- 内部：增益 = 1；
- 出口：60 ms 升余弦 1→0，`env[e-R]==1` 精确、`env[e-1]==0` 精确，连续离开内部；
- 重叠窗口：逐点取 max，不引入内部凹陷。

### 2.2 确定性测试（`corrected_C1_envelope_tests.json`，全部通过）

单一孤立窗口、两重叠窗口、两近贴窗口（间隙 5 样本）、密集合并窗口、精确边界样本、一阶导数/不连续性检查（真实 golden 84 事件与 Holdout-D E0 123 窗口上 max|Δgain| ≤ 3.3e-3）；旧实现对照组如预期失败（max|Δgain| ≈ 1）。诊断图：
- `corrected_C1_envelope_audit.png`（修正包络审计 + 新旧增益步长对比）
- `old_vs_corrected_C1_envelope.png`（全窗对比 + 首跨度四处不连续放大标注）

### 2.3 修正 HPSS 对照（单一实现，不扫参）

`H = median(|Z|, size=(1,31))`（沿时间）为谐波估计；`P = median(|Z|, size=(31,1))`（沿频率）为打击乐估计；掩码 `M = P/(H+P+1e-9)`（**分子 = 打击乐估计**）；`g = clip(0.35 + 0.65·M^0.8, 0.35, 1)`；STFT 参数与旧实现一致（n_fft 2048 / hop 512）。合成 `golden_C2_fixed = 修正C1包络 × 打击乐增强(raw)`。参数与历史完全相同，仅方向修正。

### 2.4 新评估器（`scripts/evaluator.py`，历史评估器文件未动）

- 4A 一一匹配：最优最大基数匹配（总 |Δt| 最小），容差 ±33/50/80 ms，报告 P/R/F1、未匹配预测数、未匹配 oracle 数；±80 ms 显式注明历史贪心少配（78 vs 80）；
- 4B `VISUAL_HIGH` 与 `AUDIO_STRONG` 分开报告，均不解读为物理力度；
- 4C 门支撑直接取自**生成的增益包络**：平均增益、>0 覆盖、≥0.5 覆盖、最长连续开门、开门时长分布、每个接触点的增益@t / ±20 ms / ±50 ms；
- 4D 休息段 [6,8] s 直接报告（见 §5）；
- 4E "假暴露"重定义为与预注册支撑分区的直接包络交叠：允许接触支撑 = 每个 ok 接触的 [t−40 ms, t+175 ms]（C1 pre/post + R4 元数据 ±25 ms A/V 不确定度）、已知休息支撑、无标注支撑；不按中点分类整段；
- 4F 术语：仅保留 `reference_onset_coincidence` / `reference_lowband_onset_coincidence`，明确声明**不识别邻近太鼓**；
- 4G 动态：删除 `corr(peak_ratio, raw_peak)`，改为 RAW 事件幅度 vs 输出事件幅度的 Pearson/Spearman（含漏检事件，不静默剔除）；
- 4H `unmatched_detected_output_onsets`：用真实输出起音身份 + 一一匹配，不再称"幻觉"；
- 4I 最终混音 RMS 仅作次要诊断，注明共享参考使其成为弱指标；干声差异单独给出。

评估器手算自测 6 项全部通过（`logs/evaluator_selftest.json`），包括一个贪心必败、最优匹配成功的构造用例。

## 6. 等覆盖时移对照（预注册于 `logs/predeclared_controls.json`，先声明后评分）

时移量在看任何分数之前固定：golden +7.5 s、Holdout-D +9.0 s（各为窗长一半，非对齐窗口边界/事件栅格），循环移位、占空比与包络形状严格不变。

- 保留：golden 64→50（@50 ms），holdout 54→49；
- 幅度相关性：golden Spearman 0.960→0.680（含漏检 0.680 / 仅开门 0.711）；
- 休息段：holdout 1.425→1.726 s（>0）；
- 参考起音重合（golden 12→12）几乎不变——因为它只测与循环性音乐的巧合，进一步说明该指标不反映放置正确性。

结论：**正确的时序位置承载收益**，不是"暴露等量原始音频"就能替代。单一时移、单窗，不做统计推断。

## 9. 最终决策：**A**

"A" 的含义仅为：**基础已修复到足以运行独立新录音验证阶段**——

- 修正 C1 通过全部确定性测试（增益有界、支撑外为零、单调斜坡、连续进出、重叠不降、无不连续）；
- 历史输出可精确复现（35 个工件 SHA-256 冻结于 `HISTORICAL_BASELINE_MANIFEST.json`，检查后二次校验哈希未变）;
- 修正评估器与手算一致；
- 修正指标体系自洽（休息段、混淆、置信度、术语各自归位）；
- 盲听包已就绪。

**明确不宣称**：生产就绪；来源分离；太鼓抑制；完整保留。即使听评结果良好，下一步仍是**新录音验证**（多演奏者/多场地/含显式休息与弱接触），而不是 R6。

**进入新录音阶段前必须携带的问题**（本阶段产生、无法在本阶段解决）：

1. E0 在显式休息段内产生预测（1.4 s 暴露、−1.8 dB）——检测器/候选净化问题，C1 修复不解决；
2. 音频精化（±40 ms 峰值搜索 + no_transient 关门）会删除视觉高置信接触（d43、d64）——时序精化需要视觉否决权或保留性关门策略；
3. 休息段外的"无标注暴露"（holdout E0 0.88 s）应在标注不确定度框架下复核。
